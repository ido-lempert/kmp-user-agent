- (constraint) The live demo must consume the real published @lempert/user-agent npm package (pinned version, per architecture AD-2) -- never a hand-reimplemented parse/generate in site JS. Bends design: every interactive feature request routes through 'what can the published library actually do' rather than what's convenient to fake in JS.
- (constraint) Hosting is GitHub Pages (static output only) -- no server-side component, no backend API. Bends design: every capability must be achievable as static assets + client-side JS.
- (constraint) The docs site must never become a dependency of the library (architecture AD-1/Inherited AD-4) -- it is a consumer, one direction only. Bends design: nothing in library/ may import from or reference docs-site/.
- (constraint) Guide content must cover all four MVP platforms the library ships for: Android, iOS, JVM, JS (CAP-4..6 plus CAP-1's JS guide). Bends design: a v1 that only documents JS/web is not acceptable even though the interactive demo is JS-only.
- (non-goal) Dokka-generated API reference is out of scope for v1 -- hand-written guides only (architecture Deferred).
- (non-goal) Custom domain for GitHub Pages is out of scope -- site serves at the default project-page URL (architecture Deferred/Assumption).
- (non-goal) Bot/AI-agent packs are out of scope for the generate demo's filters in v1, even though the library supports detecting/generating them -- CAP-3 covers browser/engine/os/device only (architecture AD-2/Deferred).
- (non-goal) Pre-merge CI (lint/typecheck) and a PR-preview deployment environment for the docs site are out of scope for v1 -- only publish-on-push-to-master exists (architecture Deferred).
- (non-goal) An automated 'known values' API exposed by the library itself is out of scope of this feature entirely -- CAP-3's filter/randomizer options come from a hand-maintained matrix in the docs site (architecture AD-3), not a library change. Exposing it from the library is future initiative-altitude work against the library's own spine, not this feature.
